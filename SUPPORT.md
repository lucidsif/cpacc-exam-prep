# Getting support

This project is a personal study tool that was open-sourced because others might find it useful. Support is volunteer-driven by the author.

## Where to ask

| Need | Where |
|---|---|
| **Bug** — something's broken | [Open a bug issue](.github/ISSUE_TEMPLATE/bug.yml) |
| **Wrong answer or rationale** in a practice question | [Open a wrong-answer issue](.github/ISSUE_TEMPLATE/wrong-answer.yml) — include the question id and the citation that contradicts it |
| **Accessibility bug** | [Open an accessibility issue](.github/ISSUE_TEMPLATE/accessibility.yml) — triaged ahead of other bugs |
| **Security concern** | See [`SECURITY.md`](SECURITY.md) — do **not** use a public issue for exploit details |
| **Question about the code / how to contribute** | Open a regular GitHub issue, or read [`ARCHITECTURE.md`](ARCHITECTURE.md) first |
| **Question about the AI provenance / labels** | Read [`AI_TRANSPARENCY.md`](AI_TRANSPARENCY.md) — most questions are answered there |
| **Deploy question** | See [`DEPLOY.md`](DEPLOY.md). If that doesn't cover it, open an issue. |

## What this project is not

- **Not a commercial product.** There is no SLA. Issues are answered when the author has time.
- **Not affiliated with IAAP.** Don't contact IAAP about anything here. They aren't responsible for this app's content or correctness.
- **Not a replacement for the official Body of Knowledge.** Use this *alongside* the BoK PDF and accredited training material — not instead of them.

## Response expectations

- Accessibility bugs: triaged within a week, typically faster
- Wrong-answer reports with a citation: usually fixed within a week
- Code questions / general help: best-effort; please be patient

If you're blocked and need help, please mention what you've already tried. That gets to a useful answer fastest.
